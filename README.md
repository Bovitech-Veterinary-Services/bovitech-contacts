# Bovitech Contacts

Offline-first contacts app for Bovitech Veterinary Services (Android phones + Windows computers), hosted with GitHub Pages.

**No client data is stored in this repository.** Contacts sync through the practice Google Drive (file `bovitech-contacts-data.json`, created by the app) and are cached on each device for offline use. `config.js` holds the public Google OAuth client ID. Google Contacts is updated from one designated device so phones show the tag photo on incoming calls.
